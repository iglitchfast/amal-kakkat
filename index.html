AEGIS: chiller anomaly detection

An ML system that reads industrial chiller sensor data, finds abnormal operating periods, and explains in plain language why they were flagged.

  • Handles missing values and time gaps, then builds lag and rolling-statistic features.
  • Compares a linear regression baseline against XGBoost, using time-aware train, validation and test splits.
  • Scores anomalies in context with median absolute deviation, groups them into periods, and rates severity.
  • Uses SHAP to show which signals drove each anomaly.
  • FastAPI endpoints for ingestion, training, inference, anomalies and insights, feeding a React dashboard.
  • Python
  • XGBoost
  • SHAP
  • FastAPI
  • PostgreSQL
  • SQLAlchemy
  • Next.js
  • TypeScript
  • Recharts
